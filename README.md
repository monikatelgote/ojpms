\# Online Job Portal Management System



An \*\*Online Job Portal Management System (OJPMS)\*\* developed using Java, JSP, Servlets, Hibernate, and PostgreSQL.



The system provides a platform where job seekers can create profiles, search and apply for jobs, while recruiters can post jobs, manage applications, and schedule interviews.



\## Features



\### Job Seeker



\* User registration and login

\* Create and update profile

\* View available jobs

\* Apply for jobs

\* View applied jobs

\* Track application status

\* Interview scheduling



\### Recruiter



\* Recruiter registration and login

\* Create and update recruiter profile

\* Post new jobs

\* Edit and manage posted jobs

\* View applicants

\* Shortlist candidates

\* Reject candidates

\* Schedule interviews

\## Project Architecture



The project follows a layered approach:



\* \*\*Servlet Layer\*\* – Handles HTTP requests and responses

\* \*\*Service/Business Logic\*\* – Handles application logic

\* \*\*DAO Layer\*\* – Handles database operations

\* \*\*Entity/Model Layer\*\* – Represents database entities

\* \*\*JSP Layer\*\* – Provides the user interface

\* \*\*Hibernate\*\* – Provides ORM and database interaction



\## Database



The application uses \*\*PostgreSQL\*\* as the database and \*\*Hibernate\*\* for object-relational mapping.



\## How to Run



1\. Clone this repository.

2\. Import the project into Eclipse as an existing Maven project.

3\. Configure PostgreSQL and create the required database.

4\. Update the database configuration in `persistence.xml`.

5\. Configure Apache Tomcat.

6\. Run the project on the Tomcat server.

7\. Open the application in a web browser.
